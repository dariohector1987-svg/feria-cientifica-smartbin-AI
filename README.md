# SmartBin AI – Feria Científica

Basurero inteligente que clasifica residuos reciclables y no reciclables con IA.

## Archivos
index.html · mision-vision.html · proyecto.html · contacto.html · styles.css · app.js · smartbin.py · assets/logo.svg

## Configurar (en app.js)
- `VIDEO_ID`: ID del video de YouTube.
- `EMAIL`: correo que recibe los mensajes del formulario.

## Publicar en GitHub Pages
1. Crear repositorio público `feria-smartbin-ai-2026`.
2. Subir TODO el contenido (index.html debe quedar en la raíz, no dentro de otra carpeta).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Enlace: https://TU-USUARIO.github.io/feria-smartbin-ai-2026/
